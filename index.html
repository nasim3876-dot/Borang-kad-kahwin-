Cara Muat Naik ke GitHub Pages

Ikuti 4 langkah mudah ini untuk menerbitkan kad kahwin anda secara percuma:

  1. 1
    Muat Turun Fail HTML Klik butang Muat Turun index.html di bahagian atas halaman ini.
  2. 2
    Cipta Repositori Baru di GitHub Log masuk ke github.com, klik New repository, namakan (contoh: adam-hawa) dan pastikan ia ditetapkan sebagai Public.
  3. 3
    Muat Naik Fail index.html Klik Add file > Upload files, seret fail index.html (dan fail .mp3 jika ada) kemudian klik Commit changes.
  4. 4
    Aktifkan GitHub Pages Pergi ke Settings > Pages, di bawah Branch pilih main & / (root) lalu klik Save. Pautan kad anda akan aktif dalam 1–2 minit!
